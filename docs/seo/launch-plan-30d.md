# Doki.help — 30-day SEO/content launch plan

Цель: за 30 дней заложить прочный SEO/контент-фундамент для doki.help — цифрового семейного сейфа для документов. Принцип: **15–20 качественных страниц, а не 100 статей**.

## 1. Позиционирование и аудитории

**Позиционирование:** doki.help — не облако для файлов, а семейная система порядка, напоминаний о сроках и безопасного доступа к важным документам. Тон везде спокойный, надёжный, заботливый; без паники и без обещаний абсолютной защиты.

### 5 ключевых аудиторий

| Аудитория | Боль | Контент-угол |
| --- | --- | --- |
| Семьи с детьми | Много документов на всех членов семьи, легко забыть срок детского паспорта или медполиса, файлы разбросаны по мессенджерам | Как навести порядок в семейных документах; напоминания о сроках; организация по членам семьи |
| Путешественники | Паспорта/визы/страховки с разными сроками, копии нужны под рукой в поездке | Какие документы проверить перед поездкой; где держать копии в путешествии |
| Экспаты | Виза, ВНЖ, страховки, переводы; сроки в чужой юрисдикции, риск пропустить дедлайн | Организация миграционных документов; напоминания о продлении; безопасный обмен с адвокатом/агентом |

| Самозанятые | Договоры, счета, лицензии, страховки; всё вперемешку, сроки теряются | Порядок в рабочих документах; напоминания; быстрый безопасный обмен файлами |

## 3. Пять опорных статей: H1 и структура

### 3.1. Как организовать семейные документы

- **H1:** Как организовать семейные документы: простая система для всей семьи
- Структура: вступление → почему хаос в документах опасен (мягко) → шаг 1: собрать всё в одном месте → шаг 2: разложить по членам семьи → шаг 3: отметить сроки действия → шаг 4: настроить напоминания → шаг 5: настроить безопасный доступ → нативный переход к doki.help → FAQ (3–5) → CTA.

### 3.2. Сроки действия паспорта, визы и страховки

- **H1:** Сроки действия паспорта, визы и страховки: как ничего не пропустить
- Структура: вступление → почему сроки легко потерять → какие документы имеют сроки (паспорт, виза, страховка, права) → как отслеживать вручную и почему это ненадёжно → как помогают напоминания → нативный переход к doki.help (email-напоминания) → FAQ → CTA. Отметить: детали по визам зависят от страны, сверяться с официальным источником.

### 3.3. Документы для семейной поездки за границу

- **H1:** Какие документы нужны для поездки за границу с детьми
- Структура: вступление → что произошло/почему актуально → кого касается → список документов (паспорта, визы, согласия, страховки, брони) → как подготовиться заранее → где держать копии в поездке → нативный переход к doki.help → FAQ → CTA.

### 3.4. Где хранить копии документов в путешествии

- **H1:** Где хранить копии документов, пока вы в поездке
- Структура: вступление → зачем нужны копии → варианты (бумага, мессенджеры, облако, doki.help) с плюсами и минусами → почему безопасный доступ важен → офлайн-доступ (PWA) → нативный переход к doki.help → FAQ → CTA.

### 3.5. doki.help против Google Drive

- **H1:** doki.help или Google Drive: где лучше хранить документы семьи

| Критерий | Google Drive | doki.help |
| --- | --- | --- |
| Назначение | Универсальное облако для файлов | Специализированный сейф для документов семьи |
| Организация по членам семьи | Вручную папками | Встроенная организация по членам семьи |
| Напоминания о сроках | Нет | Email-напоминания о сроках действия |
| Роли и доступ | Общий доступ по ссылке/аккаунту | Роли owner/editor/viewer, RLS (только семья видит) |
| Безопасный обмен | Ссылки без лимитов по умолчанию | Истекающие/отзываемые ссылки, лимит просмотров, журнал |
| Защита входа | Аккаунт Google | 2FA (TOTP), приватный bucket, HTTPS |
| Офлайн | Частично | PWA, офлайн-доступ |

- Структура: вступление → в чём разница подхода → таблица сравнения → когда достаточно Drive, а когда нужен doki.help → нативный переход → FAQ → CTA. Не обещать абсолютную защиту.

## 4. Идеи кейсов (4 шт.)

1. **Детский паспорт** — семья с двумя детьми чуть не забыла про истекающий детский загранпаспорт; напоминание помогло переоформить заранее.
2. **Документы для поездки** — семья собрала все документы к поездке за неделю, ничего не искали в последний момент.
3. **Документы родителей** — забота о пожилых родителях: документы в одном месте, безопасный доступ на расстоянии.
4. **Напоминание о страховке** — email-напоминание о сроке страхового полиса помогло не допустить просрочки.

Все кейсы анонимные: без имён, без точных дат, стран, номеров и маршрутов; без мед/юр/фин/миграционных обещаний.

## 8. Stack notes

- **Google Search Console (GSC) обязателен** — источник данных по запросам, кликам, показам и позициям; без него нельзя измерять и приоритизировать.
- **Claude Skills используются как папки-инструкции** — brand voice, newswriter, case study, SEO optimizer; загружаются перед написанием соответствующего контента.
- **Google Indexing API НЕ для обычных постов блога** — он предназначен только для страниц вакансий (JobPosting) и трансляций (BroadcastEvent/livestream); для статей полагаться на обычную индексацию и sitemap.
- **Arvow — только с ручной редактурой** — автогенерация без человека не публикуется.
