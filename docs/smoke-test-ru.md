# Вариант А — smoke-тест основного пути владельца (doki — «Семейный сейф»)

**Цель:** за ~15–20 минут пройти главный сценарий владельца на проде
**https://doki.help** под своим аккаунтом и убедиться, что ничего не сломано.
Подписи кнопок/полей ниже — реальные (ru-локаль).

> Вход для doki — аккаунт **parkourcafe@gmail.com** + твой пароль.
> (Логин `booberid@gmail.com` — это PET ID, не doki.)
> `doki.help` редиректит на `www.doki.help` — это нормально.

## Перед началом
- Открой сайт в обычном окне браузера.
- Включи консоль: **F12 → Console** — следи, чтобы по ходу не появлялись красные ошибки.
- Проверь **и десктоп, и мобильный** вид: в DevTools кнопка с иконкой телефона
  (Toggle device toolbar) → выбери iPhone и пройди ключевые экраны ещё раз.
- На каждом шаге смотри: нет ли вечного «крутящегося» лоадера, понятны ли тексты
  ошибок, не «разъезжается» ли вёрстка.

## Шаги

**1. Открыть сайт**
Действие: открой `https://doki.help` (перебросит на `www.doki.help`).
✅ Лендинг загружается, виден бейдж «🔐 Семейный сейф», заголовок «Все документы
вашей семьи — в одном защищённом месте», внизу «Приватно по умолчанию · RLS ·
приватный storage». В консоли нет красных ошибок.

**2. Перейти ко входу**
Действие: нажми кнопку входа на лендинге (или открой `/login` напрямую).
✅ Страница входа: бейдж «🔐 Семейный сейф», кнопка «Войти через Google», ниже форма
**Email / Пароль**, ссылка «Забыли пароль?» и переключатель «Нет аккаунта?
Зарегистрироваться».

**3. ⚠️ Проверка среды (мини-негатив)**
Действие: введи свой Email и **заведомо неверный пароль**, нажми «Войти».
✅ Появляется красное сообщение об ошибке входа — форма **не зависает** (значит,
Supabase подключён и отвечает).
❌ Если вместо ошибки бесконечный лоадер или «белый экран» — зафиксируй и сообщи.

**4. Войти**
Действие: введи Email `parkourcafe@gmail.com` и правильный пароль → «Войти».
✅ Вход проходит, перебрасывает в кабинет `/my`. Слева сайдбар «Семейный сейф» с
пунктами: **👪 Семья, 📄 Документы, 🚗 Имущество, 🔍 Поиск, ⏰ Сроки, 🔑 Доступ,
🛡️ Безопасность, 📥 Офлайн**. На телефоне меню прячется под «☰».

**5. Завести члена семьи**
Действие: на странице **«Семья»** раскрой «**+ Добавить члена семьи**». Заполни:
**Имя** (обязательно, напр. «Тест Иванов»), **Связь** (выбери из списка),
**Дата рождения** (по желанию). Нажми «**Добавить**».
✅ Появляется карточка человека в сетке.
Проверка валидации: попробуй сохранить с пустым «Имя» → браузер не даст отправить
(поле обязательное).

**6. Открыть карточку человека**
Действие: нажми на созданную карточку.
✅ Открывается `/my/members/<id>`: имя, связь, ссылка «🩺 Медкарта →», блок
документов и блок «Записи».

**7. Добавить документ БЕЗ ручного заполнения** (новая фича)
Действие: раскрой «**+ Добавить документ**». В зоне файлов нажми
«**📎 Выбрать файл**» (или «**📷 Сфотографировать**» на телефоне) и выбери тестовую
картинку/PDF. Поле «**Название**» помечено «(необязательно)» — **оставь пустым**.
Нажми «**Сохранить документ**».
✅ Документ сохраняется, открывается его страница. Поскольку название не вписывал —
оно подставилось **из имени файла**.
❌ Если ругается на место в хранилище — это сообщение о лимите, проверь, что текст
понятный.
(Кнопка «✨ Распознать даты (AI)» появляется только если включено распознавание —
может отсутствовать, это норм.)

**8. Документы по разделам + свой раздел**
Действие: открой «**📄 Документы**».
✅ Список **всех категорий** со счётчиками (🪪 Удостоверения, 🎓 Образование,
💼 Работа, 🩺 Медицина, 💳 Финансы, 🧾 Налоги, 📜 Юридические, 🗂️ Прочее).
У категории, куда попал документ, счётчик ≥ 1.
Действие: зайди в эту категорию → видишь документ и «+ Добавить документ».
Действие: вернись на «Документы», раскрой «**+ Свой раздел**», заполни «**Значок**»
(эмодзи) и «**Название раздела**» → «**Создать раздел**».
✅ Новый раздел появился в списке. Зайди в него → можно добавлять документы, есть
«Удалить раздел».

**9. Карточка документа + шаринг (главное!)**
Действие: открой документ (`/my/documents/<id>`). Разделы: «Данные», «Файлы»,
«Поделиться». В «Поделиться» задай «**Действует, дней**» (по умолч. 7), «**Лимит
просмотров**» (0 = без лимита), галочки «**Водяной знак**» / «**Скачивание**» →
«**Создать ссылку**».
✅ Появляется строка «**Активна · до <дата> · просмотров 0**» с кнопкой копирования
и «**Отозвать**».
Действие: скопируй ссылку (вид `/s/<токен>`) и открой её в **приватном окне**
(без логина).
✅ Документ открывается **без входа** — именно это увидит врач/чиновник по ссылке.
Лишних/чужих данных быть не должно.
Действие: вернись и нажми «**Отозвать**».
✅ Статус меняется на «Отозвана», ссылка в приватном окне перестаёт работать
(обнови её).

**10. Сроки (напоминания)**
Действие (подготовка): добавь любому документу «Действует до» с датой в пределах
60 дней (через добавление нового документа с этой датой). Затем открой «**⏰ Сроки**».
✅ Документ виден в списке с остатком дней; на главной «Семья» сверху — жёлтый
баннер «⏰ Скоро истекают сроки». Если сроков нет — текст «Ничего не истекает в
ближайшее время 🎉».

**11. Поиск**
Действие: открой «**🔍 Поиск**», введи часть названия документа.
✅ Документ находится в результатах.

**12. Записи и сохранность после обновления**
Действие: в карточке человека раскрой «**+ Добавить запись**», выбери «Тип»
(напр. «Анализ»), впиши «Название» → «**Сохранить запись**». Затем обнови
страницу (**F5**).
✅ Запись осталась после обновления. Рядом есть «удалить».

**13. Безопасность / 2FA**
Действие: открой «**🛡️ Безопасность**».
✅ Виден email аккаунта; блок «**Двухфакторная аутентификация (2FA)**» (можно начать
подключение — QR для приложения-аутентификатора + ввод кода); «**Оповещения о
входе**» с чипами почта/SMS; «**Недавние входы**» (твой текущий вход в списке,
возможно с меткой «новое устройство»); «**Выйти со всех устройств**». Просто
проверь, что всё грузится; завершать 2FA не обязательно.

**14. Имущество и Офлайн (бегло)**
Действие: «**🚗 Имущество**» → добавь объект (напр. машину) → в его карточке тоже
можно прикрепить документ.
Действие: на странице документа сохрани его «в офлайн», затем открой «**📥 Офлайн**».
✅ Документ доступен в офлайн-разделе.

**15. Мобильный вид + уборка**
Действие: переключись на iPhone-вид и пройди шаги 4–9 ещё раз.
✅ Меню открывается по «☰» и закрывается при переходе; формы удобны; вёрстка не
ломается.
**Уборка:** тестовый документ — «Удалить документ»; раздел — «Удалить раздел»;
запись — «удалить». Кнопки удаления **члена семьи в кабинете нет** — это нормально,
не ищи. **НЕ удаляй реальные данные.**

|---|-----------|-----------|-------------|---------------|
| 1 |           |           |             | десктоп/моб   |
| 2 |           |           |             |               |

Если на любом шаге что-то идёт не так — зафиксируй (что нажал, что ожидал, что
получил, скрин + браузер/устройство) и **продолжай дальше, не останавливайся на
первом баге**.

---

Главное отличие от PET ID: у doki **нет публичного QR-паспорта** — здесь приватный
обмен через **истекающие отзываемые ссылки** (шаг 9), и это ключевой пункт для
проверки.
