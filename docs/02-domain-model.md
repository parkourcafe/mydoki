# 02 · Доменная модель

## Иерархия

```
Аккаунт (вы)
  └─ Семья / Household (необязательно — для общего доступа)
        └─ Член семьи (вы, сын, супруг…)
              ├─ Документы (файлы): паспорт, св-во о рождении, диплом, грамота…
              └─ Записи (структурные): анализ, назначение, план питания, прививка
```

Главная сущность — **член семьи (person)**. Household — опциональная обёртка
для совместного доступа нескольких взрослых к общему архиву.

## Сущности

| Сущность | Что хранит |
|---|---|
| **User** | Аккаунт-владелец. Аутентификация, 2FA, настройки |
| **Household** | Семья. Опционально. Объединяет нескольких взрослых и членов семьи |
| **HouseholdMember** | Членство пользователя в семье + роль (owner / viewer) |
| **Member (person)** | Имя, дата рождения, связь («сын», «супруга»), фото-аватар |
| **Category** | identity · education · medical · finance/legal · other |
| **Document** | Файл(ы) + метаданные документа |
| **DocumentFile** | Физический файл в storage (у документа их может быть несколько) |
| **Record** | Структурные данные без файла (результат анализа, назначение, план питания, прививка) |
| **Share** | Временная ссылка на **один** документ: токен, срок, отзыв |
| **Reminder** | Напоминание о сроке (паспорт, виза, продление) |
| **AuditLog** | Кто/когда открывал, делился, скачивал |
| **Consent** | Согласия (PII + спец-категория «медицина»), резидентность данных |

## Атрибуты ключевых сущностей

### Member (человек)
- `full_name`, `birth_date`
- `relation` — связь с владельцем: self / spouse / child / parent / other
- `avatar` — фото-аватар (тоже в приватном storage)
- принадлежность к household (если есть)

### Document
- `member_id` — чей документ
- `category` — identity / education / medical / finance / other
- `type` — паспорт, СНИЛС, диплом, грамота, анализ… (внутри категории)
- `issued_by` — кем выдан
- `number` — номер документа
- `issued_at` — дата выдачи
- `expires_at` — **срок действия** (источник для напоминаний)
- `tags[]`, `notes`
- один или несколько `DocumentFile`

### DocumentFile
- `storage_path` — путь в приватном bucket
- `mime_type`, `size`, `original_name`
- `page` / порядок (для многостраничных)

### Record (структурная запись без файла)
- `member_id`, `kind` — analysis / prescription / nutrition_plan / vaccination
- `data` (JSONB) — поля под конкретный вид записи
- `date`, заметки; опционально связь с документом-источником

### Share
- `document_id` — делимся **одним** документом
- `token`, `expires_at`, `revoked_at`
- опции: водяной знак, разрешено ли скачивание
- связь с записями в AuditLog

### Reminder
- `member_id` / `document_id`, `due_date`, `lead_time` (за сколько предупредить)
- канал: push / email; статус (pending / sent / dismissed)

### AuditLog
- `actor` (user или анонимный получатель ссылки), `action`
  (view / download / share_create / share_open / share_revoke)
- `target` (document / file / share), `ip`, `user_agent`, `created_at`

## Категории (стартовый набор)

| Категория | Примеры документов и записей |
|---|---|
| **identity** | паспорт, загранпаспорт, СНИЛС, ИНН, свидетельство о рождении |
| **education** | дипломы, аттестаты, грамоты, сертификаты |
| **medical** | анализы, назначения, прививки, планы питания, справки |
| **finance / legal** | договоры, страховки, доверенности |
| **other** | всё остальное |

> Категории — управляемый справочник: системные значения + возможность
> пользовательских. На старте достаточно системных.
