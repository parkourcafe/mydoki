# GTM · Трек B — индонезийские HR-компании и агентства

Финализировано 08.08.2026. Ведёт локальный представитель + владелец (решения и цены).

---

## 1. Кому продаём (ICP)

**Клин: SMB рекрутинговые/стаффинговые агентства.** Высокий поток кандидатов =
максимум виральности на одного платящего клиента. Дальше — по расширению:

| Сегмент | Боль | Страница (есть в коде, BI/EN) | Тариф-гипотеза |
| --- | --- | --- | --- |
| Рекрутинговые агентства | документы кандидатов кусками в WA | `/for/recruitment-agencies` | Agency Rp 499–990k/мес |
| Hospitality Бали (виллы, отели, F&B) | текучка, сроки справок, комплектность | `/for/hospitality` | Employer Rp 149–299k/мес |
| Визовые/релокейт-агенты | пакет клиента для KITAS | `/for/visa-agents` | Agency |
| HR SMB Джаккарта | онбординг, статусы | `/for/employers` | Employer |
| Кандидаты (не платят) | «кто увидит мой KTP» | `/candidate-document-privacy`, `/for/job-seekers` | виральная сторона |

## 2. Позиционирование и оффер

**«Kirim satu ceklis — terima paket dokumen lengkap»** (`lib/segments.ts`, employers).
Одна ссылка кандидату → полный пакет документов у HR, статус «полный / не хватает»,
без регистрации кандидата, чувствительные документы (KTP/мед) — только пост-оффер
(`filterApplicationStageDocuments`). Согласие кандидата фиксируется (`consent_given`,
версия политики).

Мы **не** джоб-борд: Glints/KitaLulus ищут кандидатов, doki собирает документы уже
найденных. Отработка этого возражения — в скрипте (`docs/pricing-pilot-id.md`, §3).

**Free: 3 активные вакансии** (`employer_profiles.vacancy_limit`, дефолт 3).
Апгрейд — вручную через WhatsApp по пилотным ценам; в код тарифы не зашиваем,
пока ≥5 апгрейдов не покажут реальный порог (правило из пилота).

## 3. Воронка и метрики — инструментировано, с одной поправкой

Проверено по `lib/events.ts`: воронка обеих сторон и монетизации уже считается.

| Этап | Событие |
| --- | --- |
| HR создал вакансию/чек-лист | `vacancy_created` → `vacancy_published` (+ AI-композер: `vacancy_ai_*`) |
| Кандидат открыл | `vacancy_viewed` (src) |
| Кандидат начал | `application_started` |
| Кандидат грузит | `document_uploaded` (по типам) |
| Согласие | `consent_given` |
| **Завершил пакет** | **`application_submitted`** |
| Упёрся в лимит | `vacancy_limit_reached` |
| Пошёл платить | `upsell_contact_clicked` (channel: whatsapp/email) |

⚠️ **Поправка к контент-плану:** `docs/seo/indonesia-content-plan.md` называет
воронку `link_opened → pack_completed` — таких событий в коде **нет**. Фактические
имена: `vacancy_viewed → application_submitted`. Считать по ним; контент-план
поправить при следующей редактуре.

**Северная метрика трека: completion rate кандидата** =
`application_submitted / application_started`, гейт ≥40%.
**Виральная метрика:** K = senders-per-sender (новые отправители, пришедшие без
платного трафика, на одного активного отправителя).

## 4. Каналы и дистрибуция

### Продажи (основной контур — не масштабируемый, и это правильно)

1. **WhatsApp 1:1 + локальный представитель** — concierge-онбординг первых агентств.
   Скрипты открытия, возражений и закрытия готовы (`docs/pricing-pilot-id.md` §3).
   Массовые WA-рассылки запрещены.
2. **Офлайн-обход Бали** — коворкинги, агентства, виллы; представитель.
3. **Тёплые контакты владельца** → design-partners (1–3 пилота, concierge).

### Маркетинг (масштабируемый контур)

4. **SEO-реестры — уже в проде и уже дистрибуция:** 3 сегментные страницы,
   12 чек-листов, 4 HR-сравнения (`/vs/google-form`, `/vs/hr-whatsapp`,
   `/vs/email-attachments`, `/vs/spreadsheet-tracker`), 3 лендинга. С 21-го дня
   контент-плана — только GSC-driven расширение.
5. **Чек-листы как лид-магниты** — представитель отвечает ссылкой на
   `skck-checklist` / `employee-onboarding-11-checklist` на реальные вопросы
   в HR-сообществах (FB/WA/TG). Стартовать можно сейчас, контент готов.
6. **Кейсы** — 3 шт. по шаблону `doki-id-casestudy` (виллы / KITAS-релокация /
   массовый F&B) → блоки на сегментные страницы.
7. **Демо-видео 40 секунд** — «HR отправляет ссылку → получает пакет». Живёт
   в WhatsApp-переписке представителя и на лендинге. Одно, не лента.
8. **Google Play** — витрина этого трека: манифест BI, открывается на `/id`.
   Android подтверждён «жив»; блокеры — ключи и package name у Селены
   (`docs/launch-plan-status-2026-08-08.md`). Тип Play-аккаунта решает, есть ли
   в таймлайне closed testing 12×14 (D-U-N-S-организации освобождены).

### Не делаем до activation-гейтов

- **Платные каналы** (FB/IG/Google Ads) — гейты: ≥3 активных отправителя ·
  completion ≥40% · новые отправители органически · ≥1 «wow»-отзыв.
- **TikTok/Reels-лента** — растит кандидатскую сторону, а платит HR; петля
  запускается со стороны отправителя. Если после гейтов нужны соцсети — порядок:
  Instagram (hospitality Бали) → LinkedIn (HR Джакарта) → TikTok последним.

## 5. Ритм и ответственность

| Неделя | Представитель | Владелец |
| --- | --- | --- |
| каждая | WA-онбординги, ответы-лид-магниты в 3–5 сообществах | ценовые разговоры по скрипту, фиксация в таблицу пилота |
| Н1–2 | 1:1 обход агентств | env в Vercel (WhatsApp, представитель), sitemap в GSC |
| Н3–4 | сбор материала на 3 кейса | вычитка BI носителем; разбор GSC-запросов |
| после гейтов | — | решение о первом платном тесте + автоматизация оплат (Midtrans/Xendit) |

Правило пилота цен: **открывать с верхней границы вилки**; каждый разговор —
строка в таблице (дата · сегмент · названная цена · реакция · оплата).

## 7. Гэпы, найденные при проверке (бэклог трека)

1. **A2HS-подсказка после первого пакета (F3) — не реализована.** В коде нет
   `beforeinstallprompt` / баннера, хотя основной вход — WhatsApp-браузер, откуда
   PWA сама не «устанавливается». Это главный продуктовый гэп дистрибуции трека.
2. **Имена событий в контент-плане расходятся с кодом** (`pack_completed` vs
   `application_submitted`) — сводки строить по фактическим именам, план поправить.
3. **Демо-видео 40 сек не существует** — единственный маркетинговый артефакт,
   которого нет; нужен представителю раньше, чем любые соцсети.
4. **env-переменные представителя** (`NEXT_PUBLIC_SUPPORT_WHATSAPP`,
   `NEXT_PUBLIC_ID_REP_NAME`/`_CONTACT`) — владелец, Vercel; без них CTA-контур
   WhatsApp неполный.
5. **Вычитка BI носителем** — для страниц партии 2 (`ijazah-transkrip-checklist`,
   `candidate-document-privacy`, `fast-document-submission`) ещё не сделана.
