# Doki.help — план запуска в Индонезии (HR/агентства)

> Зеркалит скелет `docs/launch-russia.md`, но переориентирован с «семейного сейфа»
> на HR/рекрутинг/агентский B2B2C (BI/EN). Позиционирование — из `lib/segments.ts`
> (`employers`). Две дорожки: **продукт (код)** и **бизнес/владелец**.
> Связанные артефакты этой сессии: GTM-стратегия захвата, compliance-памятка
> (PSE/представитель), контент-план `docs/seo/indonesia-content-plan.md`.
> **Сводка на одной странице:** `docs/gtm-dashboard.md` — блокеры, гейты, тарифы, решения.

---

## ЧАСТЬ 0 — Go/No-Go решения (владелец)

1. **PSE-регистрация.** Иностранный PSE через OSS + локальный представитель (есть). Пока нет PSE ID — бейдж «PSE Terdaftar» не показываем (env `NEXT_PUBLIC_PSE_ID`).
2. **Compliance-gate.** Юр-тексты (Privacy/Terms/DPA) вычитывает индонезийский юрист до публикации. Плейсхолдеры уже свёрстаны.
3. **Права на продукт.** IP/бренд/домен/аккаунты — за основателем; CV партнёра только представитель (не владелец, не nominee). См. compliance-памятку.
4. **Когда включать платные каналы.** Не раньше прохождения activation-гейтов (см. ЧАСТЬ 6).

## ЧАСТЬ 1 — Аудит запуска (что готово)

Готово в коде (этой сессией): HR-разворот главной и `/for/employers`, локализация BI/EN, trust-страницы (Privacy+UU PDP, Security+incident 3×24ч, DPA, FAQ HR/кандидат, About с идентичностью), consent кандидата, аналитика воронки, шаблоны паков (villa/receptionist/general), переключатель языков EN/ID, env-плейсхолдеры (WhatsApp, представитель, PSE-бейдж).

Требует действий владельца (вне кода): env-переменные в Vercel (WhatsApp/представитель/PSE), submit sitemap в GSC, вычитка BI носителем, юр-ревью.

## ЧАСТЬ 2 — Контент (движок)

Полностью в `docs/seo/indonesia-content-plan.md`: кластеры → реестры, календарь на 30 дней, структуры, кейсы, Arvow-фиды, Brand Monitor, измерение. Ключевое: блога нет — контент идёт в типизированные реестры (`checklists`/`comparisons`/`segments`/`landings`), sitemap+hreflang авто.

## ЧАСТЬ 3 — Legal/compliance для Индонезии

- UU PDP 27/2022: права субъекта, спец-категории, трансграничность+согласие — заложено в Privacy.
- Incident 3×24 ч + контакт `security@doki.help` — на Security.
- PSE Asing + локальный представитель (см. compliance-памятку); язык договоров UU 24/2009 — к юристу.
- Юр/иммиграционный контент — только описательно + «cek syarat resmi».

## ЧАСТЬ 4 — Дистрибуция

- Веб/PWA (не «скачать из стора»). Основной вход трафика — **WhatsApp** (в т.ч. встроенный браузер).
- Add-to-Home-Screen подсказка — только после первого завершённого пака (F3, P1).
- iOS-обёртка существует (App Store), но в вебе install-CTA не промоутим.

## ЧАСТЬ 5 — Маркетинг (из GTM-стратегии)

- **Клин:** SMB рекрутинговые/стаффинговые агентства (высокий объём кандидатов = виральность).
- **Обещание:** «Kirim satu link — terima berkas lengkap».
- **Каналы (0→малый бюджет):** тёплые контакты → design-partners; локальный представитель 1:1 в WhatsApp + оффлайн-обход; HR-сообщества (FB/WA/TG); контент BI (Reels + чек-листы-лид-магниты); коворкинги Бали. Массовые WA-рассылки запрещены.
- **Виральная петля:** агентство → кандидаты (грузят по ссылке) → сохраняют сейф / рекомендуют → новые отправители. Метрика K: senders-per-sender.

## ЧАСТЬ 6 — План 30 дней (две дорожки)

**Дорожка «Бизнес/владелец»:**
- Нед. 1: env-переменные в Vercel + Redeploy; submit sitemap в GSC; конвертировать 1–3 тёплых контакта в пилоты; юристу — памятка + вопросы.
- Нед. 2: локальный представитель — 1:1 онбординг агентств; вступить в 3–5 HR-сообществ с бесплатным чек-листом-лид-магнитом.
- Нед. 3: собрать 3 кейса; вычитка BI носителем.
- Нед. 4: разбор GSC-запросов; решить, включать ли первый маленький платный тест (гейт).

**Дорожка «Продукт/код»:**
- Нед. 1: сегменты + первые чек-листы (сделано); проверить completion-воронку на пилоте.
- Нед. 2: остальные чек-листы + сравнения; nudge «сохрани сейф» (F2).
- Нед. 3: landings + внутренняя перелинковка; напоминания кандидату о недостающих (E2).
- Нед. 4: по данным GSC — усилить топ-страницы; при наличии PSE ID — включить бейдж.

**Activation-гейты (перед платными каналами):** ≥3 активных отправителя · completion кандидата ≥40% · новые отправители без платного трафика · ≥1 «wow»-отзыв.
