# 06 · Ключевые фичи

## Профиль члена семьи = «паспорт-таймлайн»
Всё по человеку в одном экране, сгруппировано по категориям (identity /
education / medical / …). Центр интерфейса — человек, а не файловое дерево.

## Загрузка + AI-автозаполнение
При загрузке файла пайплайн `doc-classify` (Claude):
- определяет **тип** документа,
- вытаскивает **номер**, **даты**, **кем выдан**,
- предлагает **категорию**.
Пользователь подтверждает/правит — меньше ручного ввода. Переиспользуем паттерн
из PET ID.

## Напоминания о сроках
Паспорт / виза / медсправка истекает — напоминание заранее (push / email),
за настраиваемое число дней. Источник — поле `expires_at` документа.

## Безопасная отправка
«Отправить диплом работодателю» / «анализ — врачу» защищённой ссылкой:
- ведёт на **один** документ,
- **истекает** по времени (`expires_at`),
- **отзывается** в любой момент (`revoke_share`),
- опциональный **лимит просмотров** (`max_views`),
- каждое открытие — в audit log.
- (Водяной знак / запрет скачивания — возможное расширение, см. открытые вопросы.)

## Поиск и фильтры
По человеку, категории, подтипу (`subtype`), дате, сроку действия
(«что истекает в ближайшие 30 дней»). Теги — возможное расширение (поля в
текущей схеме нет).

## Семейный доступ
- Пригласить супруга в household.
- Роли: **owner** (полный доступ + управление семьёй) / **editor** (чтение +
  запись) / **viewer** (только просмотр).
- Для ребёнка — опекунский доступ (документы ведёт взрослый).

## Структурные записи (records)
Рядом с файлами — данные без файла: результат анализа, назначение врача, план
питания, прививки. Удобно вести медицинскую историю человека.

## Экспорт / бэкап
Выгрузка всего архива (файлы + метаданные) для резервной копии или переноса.
Право на экспорт и удаление — часть юридического контура.

## Приоритеты (что делает продукт удобным в первую очередь)

| Фича | Зачем | Когда |
|---|---|---|
| Профиль человека + загрузка | Базовая ценность: всё в одном месте | MVP |
| Категории и метаданные | Организация и поиск | MVP |
| Напоминания о сроках | Уникальная польза vs «папка в облаке» | MVP |
| AI-автозаполнение | Снижает трение при вводе | После ядра |
| Безопасная отправка | Контроль над обменом | После метаданных |
| Семейный доступ + экспорт | Расширение на семью | Позже |
