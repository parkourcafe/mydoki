# Данные и разрешения RuStore

Этот документ является рабочей основой для раздела «Безопасность данных пользователя» и политики конфиденциальности. Перед публикацией его должен подтвердить ответственный за персональные данные.

## Какие данные обрабатывает приложение

| Категория | Примеры | Обязательно | Цель |
| --- | --- | --- | --- |
| Данные аккаунта | email, идентификатор аккаунта, имя профиля | Да | регистрация, вход, управление аккаунтом |
| Пользовательский контент | фотографии, PDF и другие загруженные документы | По выбору пользователя | хранение и показ документов |
| Реквизиты документов | название, категория, номер, кем выдан, даты, заметки | По выбору пользователя | организация и контроль сроков |
| Данные членов семьи | имя и привязанные документы | По выбору пользователя | семейное хранение |
| Данные безопасности | IP, User-Agent, время входа, журнал действий и доступа | Да | защита аккаунта, аудит, предотвращение злоупотреблений |
| Данные передачи | получатель, ссылка, срок и лимит доступа, факт просмотра | По выбору пользователя | контролируемая передача документов |
| Телефон | номер для SMS-функций, если они включены | Нет | выбранные пользователем уведомления и безопасность |

RuStore-версия **не должна** собирать или передавать:

- медицинские документы и сведения о здоровье;
- данные вакансий, резюме, откликов или работодателя;
- содержимое документов стороннему AI-поставщику;
- рекламный идентификатор и данные для таргетированной рекламы;
- геолокацию, контакты, историю звонков или данные всего файлового хранилища устройства.

## Передача данных

Данные передаются поставщикам серверной инфраструктуры только для работы сервиса. До релиза необходимо указать в политике и договорах фактических российских поставщиков API, базы данных, объектного хранилища, резервных копий, логов, email/SMS и поддержки.

Нельзя заявлять, что данные не собираются: сервис создаёт аккаунт, принимает документы и ведёт журналы безопасности.

## Защита и удаление

- Передача между приложением и сервером только по HTTPS.
- Резервное копирование Android-приложения отключено.
- Незашифрованный HTTP отключён.
- Доступ к хранилищу защищается авторизацией и серверными политиками доступа.
- Биометрия проверяется операционной системой и не передаётся на сервер.
- Пользователь может удалить документы и аккаунт в приложении.
- Сроки резервного хранения и окончательного удаления должны быть указаны в российской политике до релиза.

## Android permissions версии 1.0.1

| Permission | Назначение | Декларация для RuStore |
| --- | --- | --- |
| `android.permission.INTERNET` | работа с сервером DOKI HELP | безопасное системное разрешение |
| `android.permission.USE_BIOMETRIC` | локальная блокировка приложения | используется только после действия пользователя |
| `android.permission.USE_FINGERPRINT` | совместимость биометрии со старыми Android | используется только после действия пользователя |
| `help.doki.twa.DYNAMIC_RECEIVER_NOT_EXPORTED_PERMISSION` | внутреннее signature-разрешение AndroidX | не предоставляет доступ к данным устройства |

Приложение не запрашивает `CAMERA`: системная камера открывается через Android intent и возвращает только выбранный пользователем снимок.

## Ответы, которые нельзя отмечать

- «Приложение не собирает данные» — неверно.
- «Данные не передаются поставщикам» — неверно, пока используется серверная инфраструктура третьих лиц.
- «Медицинские данные обрабатываются» — для RuStore-сборки неверно; функция заблокирована.
- «Данные используются для рекламы или трекинга» — для RuStore-сборки неверно.
