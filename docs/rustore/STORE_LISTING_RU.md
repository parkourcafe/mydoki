# Карточка приложения RuStore

## Основные поля

**Название**

```text
DOKI HELP
```

Название совпадает с названием установленного приложения.

**Категория**

```text
Производительность
```

Если такой категории нет в текущем списке RuStore, выбрать `Инструменты`.

**Возрастное ограничение**

```text
0+
```

Подтвердить итог по анкете RuStore. Приложение предназначено для взрослых владельцев аккаунта, но не содержит возрастного контента.

**Поисковые теги, до 5**

```text
документы
хранение документов
сроки документов
семья
безопасность
```

Выбрать ближайшие варианты, если RuStore предлагает только фиксированный список.

**Краткое описание**

```text
Личные документы, сроки и защищённая передача доступа в одном месте.
```

**Подробное описание**

```text
DOKI HELP помогает хранить личные и семейные документы в одном защищённом пространстве.

Загружайте фотографии и PDF-файлы, распределяйте документы по владельцам и категориям, указывайте даты выдачи и окончания срока действия. В приложении удобно видеть, какие документы требуют внимания.

Основные возможности:
— хранение личных и семейных документов;
— загрузка файлов и фотографирование документа камерой;
— категории, реквизиты, заметки и сроки действия;
— биометрическая блокировка приложения на поддерживаемых устройствах;
— передача выбранного документа по временной ссылке;
— ограничение и отзыв ранее выданного доступа;
— история доступа и действий;
— самостоятельное удаление документов и аккаунта.

DOKI HELP не является государственным сервисом, не подтверждает подлинность документов, не определяет юридический статус и не предоставляет юридические консультации. Пользователь самостоятельно решает, какие документы загружать и кому предоставлять доступ.
```

**Что нового**

```text
Первая версия DOKI HELP для Android: личные и семейные документы, контроль сроков, нативная камера, биометрическая блокировка и временные ссылки доступа.
```

**Политика конфиденциальности**

До публичной отправки требуется отдельная политика RuStore с российской инфраструктурой и точным перечнем обработчиков. Общий URL `https://www.doki.help/privacy` пока не подходит для релиза: он описывает зарубежное хранение, AI и медицинские документы.

## Комментарий модератору

Не сохранять реальные пароли в Git. Перед загрузкой заменить значения в квадратных скобках.

```text
Тестовый аккаунт:
Email: [RUSTORE_TEST_EMAIL]
Пароль: [RUSTORE_TEST_PASSWORD]

После входа откроется раздел «Мои документы».

Сценарий проверки:
1. Войти по email и паролю.
2. Открыть владельца документов.
3. Добавить документ и сделать фотографию через кнопку «Сфотографировать».
4. Указать срок действия и сохранить документ.
5. Открыть настройки безопасности и проверить биометрическую блокировку на поддерживаемом устройстве.
6. Создать временную ссылку доступа, затем отозвать её.
7. Проверить удаление документа и доступность удаления аккаунта.

Версия RuStore не содержит вакансий, кабинета работодателя, медицинских документов, AI-обработки, рекламы и push-уведомлений.
```
