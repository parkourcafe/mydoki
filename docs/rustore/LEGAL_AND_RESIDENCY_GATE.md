# Юридический и инфраструктурный gate для России

Это инженерный release gate, а не юридическое заключение. Финальное подтверждение должен дать российский специалист по персональным данным.

## Решение на 17 июля 2026 года

**GO для внутреннего QA на вымышленных данных. NO-GO для публичного production-релиза в России.**

Причины:

1. Android-сборка открывает текущий `doki.help`.
2. Серверная часть и файлы используют Vercel/Supabase.
3. Текущая политика прямо сообщает, что серверы могут находиться за пределами РФ.
4. Общая политика описывает медицинские документы и AI, хотя RuStore-версия их блокирует.
5. Не зафиксированы доказательства уведомления Роскомнадзора, российской локализации первичного сбора, договоров с обработчиками и утверждённого согласия.

RuStore требует официальный статус оператора персональных данных, информирование пользователя и согласие. Федеральный закон № 152-ФЗ регулирует сбор, хранение, передачу, защиту и удаление персональных данных граждан РФ.

## P0 до отправки на модерацию

- [ ] Юрист подтвердил модель продукта: личное и семейное хранение документов без найма, проверки статуса и юридических консультаций.
- [ ] Определён оператор персональных данных и проверены его реквизиты.
- [ ] Подано или актуализировано уведомление в Роскомнадзор; сохранено подтверждение.
- [ ] Первичный сбор, запись, систематизация, накопление и хранение данных граждан РФ выполняются в базах данных на территории РФ.
- [ ] В России размещены или юридически подтверждены auth, API, база, объектное хранилище, журналы и резервные копии, содержащие персональные данные.
- [ ] Для возможной последующей трансграничной передачи проведена отдельная правовая процедура; она не заменяет первичную локализацию.
- [ ] Составлена карта данных: поле, источник, цель, основание, место хранения, получатель, срок, удаление.
- [ ] Подписаны договоры поручения обработки с каждым инфраструктурным поставщиком.
- [ ] Опубликована отдельная русская политика для версии RuStore с фактическими поставщиками и адресами хранения.
- [ ] На регистрации получено отдельное, конкретное и проверяемое согласие на обработку персональных данных.
- [ ] Описаны сроки хранения, удаление из backup, отзыв согласия, экспорт и ответы на обращения субъектов.
- [ ] Утверждены модель угроз, разграничение доступа, журналирование, резервное копирование и порядок реакции на инциденты.
- [ ] Создан тестовый аккаунт RuStore только с синтетическими данными.
- [ ] Production-сборка пересобрана с российским `CAP_RUSTORE_SERVER_URL` и повторно проверена.

## Definition of done

Релиз можно перевести в GO только когда в задаче приложены:

1. Письменное подтверждение юриста.
2. Подтверждение оператора/уведомления Роскомнадзора.
3. Архитектурная схема с регионами всех систем и backup.
4. Ссылки на опубликованные политику и согласие.
5. Перечень обработчиков и договорные основания.
6. Отчёт QA production-сборки без реальных документов.
