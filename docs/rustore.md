# Публикация doki.help в RuStore

Русскоязычная версия приложения для загрузки в **RuStore** — главный магазин
Android в РФ (с сентября 2025 предустановлен на всех продаваемых в РФ телефонах).

doki.help — это Next.js PWA. В RuStore его можно опубликовать двумя способами:

1. **PWA-приложение** — RuStore принимает устанавливаемые PWA напрямую по URL
   манифеста. Самый быстрый путь: ничего собирать не нужно, манифест уже готов
   (`app/manifest.ts` → `/manifest.webmanifest`).
2. **TWA (Trusted Web Activity)** — PWA заворачивается в нативный Android-пакет
   (`.aab`) через Bubblewrap. Даёт «настоящую» иконку, пуши и адресную строку без
   браузерного UI. Конфигурация лежит в `twa-manifest.json`.

Обёртка всегда открывает сайт **на русском**: точка входа TWA — `/ru/my`
(`startUrl` в `twa-manifest.json`), а middleware по префиксу `/ru` фиксирует язык
в cookie, поэтому вся дальнейшая навигация остаётся русской независимо от языка
телефона.

## Готовность PWA (чек-лист требований RuStore)

| Требование                       | Статус | Где                                   |
| -------------------------------- | ------ | ------------------------------------- |
| HTTPS                            | ✅     | Vercel / `https://doki.help`          |
| Web App Manifest                 | ✅     | `app/manifest.ts`                     |
| `name`, `short_name`             | ✅     | манифест                              |
| `description`                    | ✅     | манифест (на русском)                  |
| `lang: "ru"`, `dir: "ltr"`       | ✅     | манифест                              |
| `display: "standalone"`          | ✅     | манифест                              |
| `orientation: "portrait"`        | ✅     | манифест                              |
| `start_url`, `scope`             | ✅     | манифест                              |
| Иконки 192 и 512 (+ maskable)    | ✅     | `/icon-192`, `/icon-512`              |
| `theme_color`, `background_color`| ✅     | манифест                              |
| Service worker + офлайн          | ✅     | `public/sw.js`, `/offline`            |

(см. раздел «Сборка TWA»). Для публикации как **PWA** (способ 1) assetlinks не
нужен.

## Данные карточки в консоли RuStore

### Название

```
doki.help — семейный архив документов
```

### Короткое описание (до ~80 символов)

```
Все документы семьи в одном месте. Напоминания о сроках и безопасная отправка.
```

### Полное описание

```
doki.help — семейный цифровой сейф для документов. Все важные документы вашей
семьи в одном защищённом месте: удостоверения, образование, медицина, имущество.

Что умеет приложение:

• Хранение документов по членам семьи и категориям — паспорта, свидетельства,
  медицинские данные, документы на машину и недвижимость (ПТС, ОСАГО, договоры).
• Распознавание при загрузке: сфотографируйте документ — приложение само заполнит
  категорию, тип, номер и даты.
• Напоминания о сроках — загранпаспорт, виза, ОСАГО, страховки: напомним заранее,
  пока срок не истёк.
• Безопасный обмен — отправляйте нужный документ по ссылке, которая сама истекает
  и отзывается, с лимитом просмотров и журналом открытий.
• Семейный доступ — приглашайте супруга или родителей, разграничивайте права
  (владелец / редактор / просмотр).
• Поиск по всем документам и экспорт архива.
• Работает офлайн, устанавливается на телефон как обычное приложение.

Безопасность — ядро сервиса: приватное хранилище, изоляция данных между семьями,
двухфакторная аутентификация (TOTP). Ваши документы видны только вам и тем, кому
вы сами открыли доступ.
```

### Ключевые слова / теги

```
семейный архив документов, хранение документов, напоминание о сроках,
загранпаспорт, ОСАГО, виза, сейф для документов, документы семьи,
медицинская карта, сканер документов
```

## Графические материалы

Загружаются в консоли RuStore (в манифесте не требуются):

- **Иконка**: PNG 512×512, без прозрачности по краям для maskable-версии. Исходник —
  `/icon-512` (генерируется `app/icon-512.tsx`).
- **Скриншоты**: минимум 3, телефон вертикально (например 1080×1920 или 1284×2778).
  Рекомендуемые экраны: главная «Семья» (`/ru/my`), список документов
  (`/ru/my/documents`), карточка с распознаванием, экран сроков
  (`/ru/my/reminders`), безопасная отправка (`/ru/my/share`).
- **Баннер/обложка** (если требуется форматом карточки): 1080×607.

Снять скриншоты можно из установленного PWA или прогнав страницы в мобильном
вьюпорте (Playwright уже настроен — см. `playwright.config.ts`).

## Способ 1. Публикация как PWA (быстрый путь)

1. В консоли RuStore (вход по VK ID) → «Создать приложение» → тип **PWA**.
2. Указать URL манифеста: `https://doki.help/manifest.webmanifest`.
3. Заполнить карточку текстами и графикой выше.
4. Отправить на модерацию.

---

## Способ 2. Сборка TWA (.aab через Bubblewrap)

Требуется Node 18+ и JDK 17.

```bash
# 1. Установить Bubblewrap
npm i -g @bubblewrap/cli

# 2. Инициализировать проект из живого манифеста
#    (twa-manifest.json в корне репозитория — готовый шаблон с нашими
#     значениями: packageId help.doki.twa, startUrl /ru/my, цвета, ярлыки)
bubblewrap init --manifest https://doki.help/manifest.webmanifest

# 3. Собрать AAB (создаст ключ подписи android.keystore при первом запуске)
bubblewrap build
```

Результат — `app-release-bundle.aab` для загрузки в RuStore.

### Digital Asset Links (обязательно для TWA)

Чтобы TWA открывался без адресной строки, домен должен подтвердить связь с
приложением:

1. Возьмите SHA-256-отпечаток сертификата подписи:
   - если подписываете сами — `keytool -list -v -keystore android.keystore -alias doki`;
   - если включена **подпись приложений RuStore** — возьмите отпечаток в консоли
     RuStore (раздел подписи приложения).
2. Впишите его в `public/.well-known/assetlinks.json` вместо
   `REPLACE_WITH_SHA256_FINGERPRINT_OF_YOUR_SIGNING_KEY`.
3. Задеплойте — файл должен отдаваться по
   `https://doki.help/.well-known/assetlinks.json` со статусом 200 и типом
   `application/json` (проверено: middleware его не переписывает, редиректов нет).

`packageId` в `twa-manifest.json` (`help.doki.twa`) и `package_name` в
`assetlinks.json` должны совпадать.

## Итоговый чек-лист перед отправкой

- [ ] Манифест отдаётся по `https://doki.help/manifest.webmanifest`, `lang: "ru"`.
- [ ] Тексты карточки и скриншоты подготовлены (раздел выше).
- [ ] Политика конфиденциальности и удаление данных доступны по ссылкам.
- [ ] (TWA) `assetlinks.json` заполнен реальным отпечатком и отдаётся 200.
- [ ] (TWA) `packageId` == `package_name`.
- [ ] Приложение открывается на русском (`/ru/my`), навигация остаётся русской.
- [ ] Юридический блок 152-ФЗ закрыт (хостинг ПДн в РФ, оператор в РКН).
