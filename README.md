# Family Vault — семейный цифровой сейф документов

> Все документы вашей семьи — в одном защищённом месте. Для каждого члена
> семьи: удостоверения, образование, медицина, награды. Напоминания о сроках,
> быстрый поиск и безопасная отправка нужного документа по ссылке, которая
> сама истекает.

**Статус:** MVP реализован — Next.js + Supabase, схема применена к проекту. Это
одновременно единый источник правды (`docs/`) и рабочее приложение.

**Репозиторий:** `parkourcafe/mydoki` · **Рабочая ветка:** `claude/cool-volta-pdpl4t`

---

## Приложение (MVP)

**Стек:** Next.js 15 (App Router) · Supabase (Postgres + RLS + Storage + Auth) · Tailwind.

**Что работает**
- Регистрация / вход (email + пароль), 2FA (TOTP) на `/my/security`.
- Семья создаётся автоматически (`create_household`); добавление членов семьи.
- Документы по категориям + загрузка файлов в приватный bucket `vault-files`.
- Просмотр файлов по коротким signed URL; теги, метаданные, заметки.
- Напоминания о сроках (`/my/reminders`).
- Безопасный обмен: истекающие отзываемые ссылки с лимитом просмотров; публичная
  страница `/s/[token]` через RPC `get_shared_document`; аудит каждого открытия.

### Быстрый старт

```bash
cp .env.example .env.local   # вписать ключи проекта Supabase
npm install
npm run dev                  # http://localhost:3000
```

`.env.local`:
- `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY` — публичные (клиент).
- `SUPABASE_SERVICE_ROLE_KEY` — **секрет, только сервер**; нужен `/s/[token]`, чтобы
  подписать файл анонимному получателю ссылки. Взять в Supabase Dashboard → API.

### Деплой

Vercel: импортировать репозиторий, задать те же env-переменные. Схема уже
применена к проекту Supabase `uuopxzlcmzdtwebottar` (миграции
`init_family_vault_schema`, `harden_function_grants`).

### Статус проверки

- ✅ `tsc` без ошибок; `next build` успешно (8 маршрутов).
- ✅ Маршрутизация / auth-guard / SSR проверены на прод-сервере.
- ✅ **RLS-изоляция проверена** реальным тестом: `create_household` + вставка/чтение
  под двумя пользователями — второй не видит данные первого.
- ⚠️ Прямые запросы приложения к `*.supabase.co` из облачного контейнера Claude
  блокируются сетевой политикой egress, поэтому полный UI-прогон возможен только
  при деплое (Vercel) или после добавления `*.supabase.co` в egress allowlist.

## Что это

Family Vault — это «**PET PASS, но для людей**»: тот же проверенный паттерн
(сущность → её документы → приватный доступ владельца), но с принципиально
другим профилем риска. Здесь хранятся настоящие документы человека — паспорт,
свидетельство о рождении ребёнка, медицинские данные. Поэтому **безопасность
здесь не фича, а ядро архитектуры**.

Ключевая сущность — не «питомец», а **член семьи (person)**. К нему привязаны
документы и структурные записи.

## Чем отличается от PET ID

| | PET ID | Family Vault |
|---|---|---|
| Главная сущность | Питомец | Член семьи (человек) |
| Доступ по умолчанию | **Публичный** (QR на ошейнике) | **Приватный**. Публичности по умолчанию нет |
| Профиль риска | Низкий | Высокий (удостоверения + медицина) |
| Обмен | Открытая страница питомца | Только explicit share: 1 документ, TTL, отзыв, лог |
| База данных | Общая с PET ID | **Отдельная** — другой контур риска |

Переиспользуем **паттерны и компоненты** PET ID (приватный bucket + signed
URL, RLS по принадлежности к семье, AI-классификация документов, напоминания),
но **не общую базу и не общий проект**.
