# MyDoc — семейный цифровой сейф документов

> Все документы вашей семьи — в одном защищённом месте. Для каждого члена
> семьи: удостоверения, образование, медицина, награды. Напоминания о сроках,
> быстрый поиск и безопасная отправка нужного документа по ссылке, которая
> сама истекает.

**Статус:** черновик ТЗ / единый источник правды (v0.1). Кода приложения и
миграций пока нет — это документ, по которому мы будем строить продукт.

**Репозиторий:** `parkourcafe/mydoki` · **Рабочая ветка:** `claude/cool-volta-pdpl4t`

---

## Что это

MyDoc — это «**PET PASS, но для людей**»: тот же проверенный паттерн
(сущность → её документы → приватный доступ владельца), но с принципиально
другим профилем риска. Здесь хранятся настоящие документы человека — паспорт,
свидетельство о рождении ребёнка, медицинские данные. Поэтому **безопасность
здесь не фича, а ядро архитектуры**.

Ключевая сущность — не «питомец», а **член семьи (person)**. К нему привязаны
документы и структурные записи.

## Чем отличается от PET ID

| | PET ID | MyDoc |
|---|---|---|
| Главная сущность | Питомец | Член семьи (человек) |
| Доступ по умолчанию | **Публичный** (QR на ошейнике) | **Приватный**. Публичности по умолчанию нет |
| Профиль риска | Низкий | Высокий (удостоверения + медицина) |
| Обмен | Открытая страница питомца | Только explicit share: 1 документ, TTL, отзыв, лог |
| База данных | Общая с PET ID | **Отдельная** — другой контур риска |

Переиспользуем **паттерны и компоненты** PET ID (приватный bucket + signed
URL, RLS по `owner_user_id`, AI-классификация документов, напоминания), но
**не общую базу и не общий проект**.
